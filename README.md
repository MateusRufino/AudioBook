<h2>Audiobook Project</h2>

<h3>Project Description</h3>

<p>This project is an interactive audiobook developed using web technologies: JavaScript, CSS and HTML. The goal of this project is to provide a book listening experience directly in a web browser, with intuitive controls and a user-friendly interface.</p>

<h3>Features</h3>

<p>Audio Player: The project includes a customized audio player, where the user can start, pause, fast forward and rewind the audiobook playback.</p>

<p>Chapters: The interface allows navigation by chapters, facilitating access to different parts of the audiobook. User can select a specific chapter to start playback.</p>

<p>Custom Style: Using CSS, the project has a modern and responsive interface, suitable for different screen sizes, providing a good experience on both mobile devices and desktops.</p>

<p>Interactive JavaScript: Player control logic, chapter navigation, and other interactions are managed by JavaScript, offering a fluid and dynamic user experience.</p>
